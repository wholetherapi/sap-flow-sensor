# Sap Flow Sensor

Sap Flow Sensor is a thermal sap-flow probe for orchard transpiration studies
(kit BH-SF-400).

## Planned contents

- `hardware/` - probe housing, calibration fixture and carrier board
- `firmware/` - the sampling firmware and serial protocol
- `docs/` - installation notes and calibration procedure

Everything listed above is still being prepared. Watch this repository for the
release announcement; no files are downloadable yet.
